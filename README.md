## 🎯 Overview

Welcome to the **SPG Hackathon 2025** - an innovative dual-phase hybrid hackathon that transforms traditional competition into collaborative innovation! This unique event brings together students, professionals, data scientists, and geoscientists to tackle AI-driven challenges in subsurface data analysis.

### 🌟 What Makes Us Different?

- **🔄 Dual-Phase Approach**: Virtual screening followed by collaborative onsite finals
- **🤝 Cross-Disciplinary Teams**: Students + Professionals + Geoscientists + Data Scientists
- **📊 Low-Code/No-Code**: Accessible to all skill levels using Dataiku platform
- **🧠 AI-Powered**: Focus on ML, NLP, and AI techniques for subsurface analysis

---

## 🚀 Challenge Statement

### The Problem We're Solving

The subsurface industry generates **massive volumes** of technical content:
- 📊 Well logs and seismic reports
- ⚡ Drilling performance records
- 🗺️ Geological assessments
- 📋 Technical documentation

**Challenge**: Manual extraction of insights is time-consuming, error-prone, and inefficient.

**Our Solution**: Leverage AI, ML, and NLP techniques to extract, organize, and interpret meaningful insights from curated subsurface documents.

## ⚡ Quick Start

### Prerequisites
- Python 3.8+
- Dataiku DSS (provided during hackathon)
- Git
- Docker (optional)

### 1. Clone Repository
```bash
git clone https://github.com/your-team/spg-hackathon-2025.git
cd spg-hackathon-2025
```

### 2. Setup Environment
```bash
# Using conda
conda env create -f environment.yml
conda activate spg-hackathon

# Or using pip
pip install -r requirements.txt
```

### 3. Configure Dataiku
```bash
# Copy and modify configuration
cp config/dataiku_config.example.json config/dataiku_config.json
# Edit with your Dataiku instance details
```

### 4. Run Initial Setup
```bash
python setup.py develop
```
